# Changelog

## 1.0.2

- Embed now sits in the Simplify group of Pelican's admin menu, together with the other Simplify add-ons,
  in the same order everywhere. This works with or without the Simplify core.

## 1.0.1

- The join address on the public server list stays on one line. Before, it could break in the middle of the port. Cards are a bit wider, and a host name that is too long is shortened while the port stays whole.

## 1.0.0

- First version as a plugin of its own. Websites that use `/simplify/embed.js` or `/simplify/embed` keep working.
